# Terraform
Includes a Collection of Terraform Templates for the purpose of supporting multiple Technologies in Azure

### AzureMigrate_Training Lab
Deploys a Training lab for multiple ABRS engineers with the same set of VMs

### VMwareToAzure_Repro Lab
Deploys a VMware to Azure Site Recovery Lab including: Windows / Linux VMs, Appliance, Storage Account, And RSV
